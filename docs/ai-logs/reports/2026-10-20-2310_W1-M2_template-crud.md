想亲手造一条模板,可以启动后端后用 curl:

```bash
# 1) 注册并拿到 token
curl -X POST http://localhost:3000/api/auth/register \
  -H 'content-type: application/json' \
  -d '{"account":"13800000001","password":"pass1234","nickname":"家长"}'
# 2) 建家(返回 family.id)
curl -X POST http://localhost:3000/api/families -H 'authorization: Bearer <token>' \
  -H 'content-type: application/json' -d '{"name":"我们家"}'
# 3) 建模板 → 期望 201
curl -X POST http://localhost:3000/api/families/<fid>/templates -H 'authorization: Bearer <token>' \
  -H 'content-type: application/json' \
  -d '{"title":"洗碗","timeOfDay":"14:00","repeatRule":"weekly:1,3,5","maxPoints":3}'
# 4) 列表 → 期望 200 {templates:[...]}
curl http://localhost:3000/api/families/<fid>/templates -H 'authorization: Bearer <token>'
# 5) 暂停 → 期望 200;再查列表 → 空;带 ?status=all → 仍在
curl -X PATCH http://localhost:3000/api/families/<fid>/templates/<tid> \
  -H 'authorization: Bearer <token>' -H 'content-type: application/json' -d '{"status":"paused"}'
```
